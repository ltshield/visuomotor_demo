# Visuomotor Learning Lab

A short browser-based reaching activity for an undergraduate neuromechanics course.
Students make quick mouse reaches to targets, then inspect their own trajectories and errors.

> Work in progress. Full documentation is added with the final milestone.

## Run locally

```bash
npm install
npm run dev        # development server
npm test           # unit tests (Vitest)
npm run build      # type-check + production build into dist/
npm run preview    # serve the production build
```

Requires Node 22.12 or newer. The activity itself needs desktop Chrome or Edge and a physical mouse.
